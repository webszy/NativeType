# @nativetype/web

NativeType website. Nuxt 4 and TypeScript. Static files come from `nuxt generate`.

This package is part of the pnpm workspace. Run these commands from the repository root:

```bash
pnpm --filter @nativetype/web dev
pnpm --filter @nativetype/web build
pnpm --filter @nativetype/web generate
pnpm --filter @nativetype/web preview
pnpm --filter @nativetype/web typecheck
```

## Routes

| Route | Page |
| --- | --- |
| `/` | Homepage |
| `/privacy` | Privacy Policy |
| `/support` | Support |
| `/changelog` | Changelog |

These pages are placeholders. The default layout sets `noindex, follow`. No production domain or canonical URL is configured.
