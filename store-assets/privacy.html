NativeType Privacy Policy

Write in your language. Publish in another.

Last updated: October 4, 2026

Short version: NativeType only accesses text you enter in supported web composers when necessary to provide translation functionality. NativeType does not sell your data, does not use your draft text for advertising, and does not transmit your draft text to NativeType-controlled servers.

1. About NativeType

NativeType is a browser extension that helps users write in one language and publish in another directly inside supported websites.

The current version supports translation inside the X post composer, including translation preview and one-click replacement of the text entered by the user.

2. Information NativeType Accesses

To provide its core translation functionality, NativeType may access website content that you actively enter into a supported text composer.

For example, when using NativeType on X, the extension may read the text you type into the post composer so it can generate a translation preview and replace the text when you explicitly choose to do so.

NativeType does not intentionally collect:

  • Your name or identity information
  • Email addresses or account credentials
  • Passwords or authentication information
  • Payment or financial information
  • Health information
  • Precise location information
  • Browsing history

3. How Your Text Is Used

Text accessed by NativeType is used only to provide the extension's translation workflow.

This includes:

  • Detecting text entered into a supported composer
  • Generating a translation
  • Displaying a translation preview
  • Replacing the original text when you explicitly request replacement

NativeType does not use your text for advertising, profiling, credit decisions, or purposes unrelated to the extension's translation functionality.

4. Translation Processing

The current version of NativeType uses Chrome's built-in Translator API to perform translation.

NativeType does not transmit the text you enter to NativeType-controlled servers for translation.

Chrome and the browser environment may independently manage browser components, language models, updates, diagnostics, or related platform functionality according to Google's own terms and privacy policies. NativeType does not control those browser-level processes.

5. Data Storage and Retention

NativeType does not maintain a server-side database containing your draft text or translations.

Text accessed for translation is processed only as needed to provide the requested functionality and is not retained by NativeType after that functionality is completed.

6. Data Sharing and Sale

NativeType does not sell user data.

NativeType does not transfer user data to third parties for advertising, marketing, credit assessment, data brokerage, or purposes unrelated to the extension's single purpose.

7. Website Permissions

NativeType requests access only to supported websites where its translation functionality needs to operate.

In the current version, access to x.com is used to:

  • Detect the X post composer
  • Read text entered by the user
  • Display the NativeType translation interface
  • Replace composer text when requested by the user

These permissions are not used to monitor unrelated browsing activity.

8. Analytics and Tracking

NativeType does not currently use advertising trackers or behavioral analytics to monitor your browsing activity.

9. Children's Privacy

NativeType is a general-purpose productivity tool and is not designed specifically for children. NativeType does not knowingly collect personal information from children.

10. Changes to This Privacy Policy

This Privacy Policy may be updated when NativeType's functionality, permissions, or data practices change.

Any material changes will be reflected on this page together with an updated revision date.
